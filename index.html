Entry process

  1. Enter vehicle details.
  2. System checks for duplicate active tickets.
  3. Available compatible slot is selected.
  4. Ticket and QR code are generated.
  5. Slot status changes to occupied.
The system uses simulated slot data. No physical camera or sensor is connected.
